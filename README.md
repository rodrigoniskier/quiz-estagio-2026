# Quiz: Princípios dos Testes Diagnósticos

Avaliação interativa em uma única página HTML, para estudar princípios de testes diagnósticos de
laboratório.

## Problema, público e resultado

**Problema.** Estudar técnicas de laboratório exige praticar com feedback imediato, não apenas ler.

**Para quem.** Estudantes da área da saúde que estudam técnicas de laboratório.

**O que entrega.** Quiz com explicação por questão sobre espectrofotometria, centrifugação, imunocromatografia, morfologia leucocitária, parasitologia e fita reativa de urina. O gabarito só aparece após a segunda tentativa, quando ela for necessária.

**Tecnologias.** HTML, CSS, JavaScript.

**Qualidade e evidências.** Arquivo único, sem dependências e sem backend. Este repositório não tem testes automatizados.

## Como usar

Abra `index.html` em qualquer navegador moderno. Para publicar, ative o GitHub Pages na branch `main`.
